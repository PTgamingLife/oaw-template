# OAW 測試:一鍵開啟手機網頁

<walkthrough-tutorial-duration duration="1"></walkthrough-tutorial-duration>

## 第 1 步:貼上指令並執行

1. 點下方灰色指令框 **右上角左邊那個小圖示**(終端機圖示),指令會自動貼到下方黑色終端機
2. 點一下黑色終端機,按鍵盤的 **Enter**

```bash
bash ~/cloudshell_open/oaw-template/oaw/serve.sh
```

終端機印出網址後,再按下方「下一步」。

## 第 2 步:開啟網頁

點終端機裡印出的網址。

打不開的話:點右上角 <walkthrough-web-preview-icon></walkthrough-web-preview-icon> **網頁預覽** →「在通訊埠 8080 上預覽」。

看到「✅ 你的 Cloud Shell 網頁已開啟」,按「測試連線」顯示「連線成功」就完成了。
