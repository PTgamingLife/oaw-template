# OAW 測試:一鍵開啟手機網頁

<walkthrough-tutorial-duration duration="1"></walkthrough-tutorial-duration>

## 啟動

點下方指令右邊的 **貼到終端機** 圖示,再按 Enter:

```bash
bash ~/cloudshell_open/oaw-template/oaw/serve.sh
```

終端機會印出一個網址,點它開啟。

## 打不開網址時

點右上角 <walkthrough-web-preview-icon></walkthrough-web-preview-icon> **網頁預覽** →「在通訊埠 8080 上預覽」。

## 完成

看到「✅ 你的 Cloud Shell 網頁已開啟」,按「測試連線」顯示「連線成功」就代表成功。
