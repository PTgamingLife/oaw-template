# oaw-template

LINE OA + LIFF + Supabase 一鍵開站範本(測試版)。

## 手機測試

[![Open in Cloud Shell](https://gstatic.com/cloudssh/images/open-btn.svg)](https://shell.cloud.google.com/cloudshell/editor?cloudshell_git_repo=https%3A%2F%2Fgithub.com%2FPTgamingLife%2Foaw-template&cloudshell_tutorial=oaw%2Ftutorial.md)

1. 點上面按鈕,用 Google 帳號登入
2. 依右側教學面板:點指令旁的圖示貼到終端機 → Enter
3. 點終端機印出的網址,看到「✅ 你的 Cloud Shell 網頁已開啟」即成功
